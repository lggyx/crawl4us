# crawl4us

LLM-ready web crawler: any website into clean Markdown.

Built for the G10 crowdtest — a Coding-class task that turns real engineering work
into a model evaluation exercise.

## Status

Early design phase. See [DESIGN.md](DESIGN.md) for the working design notes.

## Goals

- Turn any web page into clean, LLM-ready Markdown
- Handle JavaScript-heavy pages and lazy-loaded content
- Extract structured data without requiring an LLM key
- Be usable as a library, a CLI, and a self-hosted server
